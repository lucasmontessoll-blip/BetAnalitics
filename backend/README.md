# BetAnalytics PRO - Kit API 100%

Este kit entrega a base real que faltava no app:

- Login real
- Cadastro real
- Banco Supabase
- VIP real com data de expiração
- Pagamento PIX Mercado Pago
- Webhook Mercado Pago
- Favoritos salvos por usuário
- Histórico de assertividade salvo
- Admin com estatísticas reais
- Serviço front-end para conectar o App.jsx

## Arquivos

- `server.js` -> API Node/Express para Render
- `package.json` -> dependências da API
- `.env.example` -> variáveis do Render
- `supabase_schema.sql` -> tabelas do banco
- `apiReal.js` -> coloque em `src/services/apiReal.js`
- `COMO_INSTALAR.txt` -> passo a passo no VS Code/Render/Supabase

## Observação

Não coloque suas chaves secretas dentro do código.
Use Environment Variables no Render.
