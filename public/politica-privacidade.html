Política de Privacidade

Última atualização: 18/07/2026

Esta Política de Privacidade explica como o aplicativo BetAnalytics PRO trata informações do usuário.

1. Finalidade do aplicativo

O BetAnalytics PRO é uma ferramenta informativa de análise esportiva, gestão de banca, favoritos, alertas e recursos de inteligência artificial. As informações apresentadas não garantem resultados.

2. Dados que podem ser utilizados

O aplicativo pode utilizar dados como nome, e-mail, favoritos, preferências, histórico de análises, configurações locais e informações necessárias para login, assinatura ou funcionamento dos recursos.

3. Dados locais

Algumas informações podem ser salvas localmente no dispositivo, como favoritos, histórico IA, configurações e dados demonstrativos.

4. Pagamentos

Quando houver assinatura ou pagamento, o processamento poderá ser feito por provedores terceiros, como Mercado Pago. O aplicativo não deve armazenar dados completos de cartão.

5. Serviços terceiros

O aplicativo pode usar serviços externos para dados esportivos, análise, hospedagem, autenticação, pagamentos e links parceiros.

6. Jogo responsável

O aplicativo é destinado a maiores de 18 anos. As análises são informativas e não garantem lucro. O usuário é responsável por suas decisões.

7. Contato

Para dúvidas, entre em contato pelo e-mail: betanlyticspro@gmail.com
